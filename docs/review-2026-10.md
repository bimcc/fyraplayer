# 2026-10 架构、质量与清理复盘

本轮以 1.0.2 工作区为基线；变更尚未发布。目标是修正已复现问题、明确职责、减少过时材料，同时保留有效回归保障。

本文按阶段保留执行结果与当时限制；当前契约以 [架构](architecture.md)、[播放会话](playback-sessions.md) 和 [WebTransport](webtransport.md) 为准。历史 v1/v2 名称仅表示当时实现，当前已合并为唯一协议；最新结果见文末第十三阶段。

## 架构结论

播放器负责播放与通用元数据提取，fyraklv 独立负责 KLV/MISB 解析、同步和离线 TS 处理。没有把 KLV 解析移入播放器，也没有引入双向依赖。新增应用层 createFyraKlvPlugin 示例，注入 KLVStreamManager；MetadataBridge 命名泛化，旧 KlvBridge 保持兼容。

DASH、UI、PanoramaLite 通过插件启用。主入口和 /core 仍广泛导出；本轮没有进行破坏兼容的物理拆包。两套 TS demux 和实验 WebCodecs/WASM 管线仍服务于实际场景，继续保留。完整说明见 [架构](architecture.md) 和 [KLV 接入](klv-integration.md)。

## 已处理问题

| 问题 | 处理 |
| --- | --- |
| 加载中切源丢失，旧完成覆盖新状态 | 串行加载队列、代次失效、合并初始化、跳过过时切源 |
| destroy 后旧任务重启统计/回调 | 立即失效和解绑，等待最终 Tech 清理，销毁幂等 |
| 控制中间件延迟完成后操作新源或已销毁实例 | 控制路径校验加载代次和销毁状态 |
| HLS 主源失败跳过 HLS 备用地址 | URL 失败与显式禁用 Tech 分离 |
| 受限 localStorage 阻断构造 | 插件 context 惰性、安全获取 |
| KLV 时间戳精度与网络分片导致不完整数据 | 保留可选 pts90k；修正 33 位 PTS；按 PES 长度拼装和去填充 |
| File 对 MTS/FLV 路由及 MSE 错误不一致 | 统一容器识别；不支持时拒绝加载，play 拒绝回报运行时错误；不等待直播首帧，停止使 loader/迟到回调失效 |
| 发布包导入即访问 DOM | UI 元素基类/注册增加无 DOM 防护；真正创建 UI 仍需浏览器 |
| 示例与文档条件错误 | DASH 显式插件和 vendor URL；metadata 明示 experimental 与时间锚点 |

## 第五阶段：控制栏与错误地址停止（2026-10-13）

PanoramaLite 用静态 SVG 替换字符图标，采用普通播放器的贴底渐变、细进度条和一排操作按钮；音量滑杆在悬停/聚焦时展开，播放闲置 3 秒隐藏，暂停保持可见。窄容器隐藏 loop，保留时间和主要操作。去掉悬浮圆角长条，控制区直接贴近画面底边。

## 第十二阶段：WebTransport 慢解码启动与多路回归（2026-10-14）
